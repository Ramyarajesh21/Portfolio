# My React Portfolio

A personal portfolio for Ramya S, a Python Full Stack Developer.

## Technologies

- React.js
- TypeScript / JavaScript
- HTML
- CSS

## Install

```bash
npm install
```

## Run locally

```bash
npm run dev
```

Open the local URL printed in the terminal to view the portfolio.

## Build for deployment

```bash
npm run build
```

The production files are created in `dist/`. Upload or deploy those files using your hosting platform's instructions.

## Project structure

- `app/page.tsx` — the main portfolio page and its sections.
- `app/globals.css` — the portfolio styling and responsive layout.
- `app/layout.tsx` — the common page layout and site metadata.
- `public/` — images and other public files. The profile photo is `public/Ramya.png` and is loaded with the deployment-safe path `/Ramya.png`.
- `package.json` — project dependencies and commands.
